You can filter the dashboard by an event. Choose Event to keep the visitors who did it, or "is not" for those who did not, with everything they did that day in view; Event property does the same for an event that carried a given value, such as the plan picked at signup. A funnel's page, Journeys and Settings → Export take the same filter, and a value in the Events block or an outbound link filters with one press.
